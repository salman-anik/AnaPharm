# AnaPharm

**AnaPharm** is an advanced interactive 3D Human Anatomy & Clinical Pharmacopoeia mobile application built with React Native, Expo, and Three.js WebGL.

- **Developer:** Salman Anik ([@salmananik](https://github.com/salman-anik))
- **Repository:** [https://github.com/salman-anik/AnaPharm](https://github.com/salman-anik/AnaPharm)

### Features
- **Interactive 3D Human Anatomy:** Complete human body with realistic body surface / skin, head, neck, torso, arms, hands & fingers, pelvis, thighs, legs, and feet.
- **Dynamic Physiology:** Actively beating heart (BPM control), pulmonary lung expansion/contraction, and circulating blood particles.
- **Explosive Disassembly & Layered Dissection:** Smooth normal vector layer separation with 360° turntable orbit and pinch-to-zoom.
- **Complete Clinical Pharmacopoeia (2,594 Generics):** 2,590+ generic monographs with generic names in English, primary indications & mechanisms of action in Bangla, dosage guidelines, precautions, side effects, and top Bangladesh commercial brand names (33,200+ brands mapped).
- **Dual Theme Support:** Dark Mode & Light Mode with custom studio medical lighting and frosted anatomical silhouettes.
